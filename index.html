Operating principles

Responsible by design.

Approved access only

Documented APIs, authorized affiliate feeds, or user-assisted inputs—never hidden shortcuts.

No scraping workarounds

No CAPTCHA bypass, browser automation, or undocumented private endpoints.

Privacy and security

Credentials stay outside source control, and personal data collection is minimized.

Test before release

Every meaningful change is validated with regression tests and a clear rollback path.
